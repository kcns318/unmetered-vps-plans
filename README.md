## 一、“无限流量”到底限的是什么

### unmetered 与 unlimited 不是一回事

**Unmetered** 的商业模式是不按 GB 计费，你跑多少都不加钱，但端口速率固定，比如锁死 1Gbps 或 10Gbps。**Unlimited** 承诺既不限流量也不限速，实际上几乎每家都会在 ToS 里塞一条公平使用条款，典型写法是“连续 7 天平均速率超过 X Mbps 视为违规”。

前者的限制条件是明确的速率上限，后者的限制条件是模糊的条款解释权。买之前把 ToS 拉到最下面看两分钟，比看十篇测评有用。

### 端口速率决定真实上限

一台标着 1Gbps unmetered 的机器，把端口 24 小时跑满，一个月理论值是 **约 324TB**（1Gbps ≈ 125MB/s，一天约 10.8TB，30 天约 324TB）。这个数字看着像天文数字，但有三重折扣要打：

1. 单 IP、单连接限速，很多商家只对多线程放开；
2. 邻居吵闹，同一宿主机上其他 VPS 抢带宽；
3. 跨网互联拥堵，国际出口高峰期掉速。

按同样口径往下推：500Mbps 月上限约 162TB，200Mbps 约 65TB，100Mbps 约 32TB。下面所有“理论上限”的折算都基于这个算法，是满速理想值，不是你能稳定拿到的速度。

### 三个新手容易踩的坑

**把端口速率当实际速度。** 标 1Gbps 不等于你永远跑 1Gbps，买前用测试 IP 在自己网络环境里测一遍，比看参数靠谱。

**忽视 fair use 条款。** “连续 7 天平均超过 X Mbps 视为违规”这类条款不写在套餐页，只写在服务条款里。

**只看首发价不看续费价。** 便宜的不限流量机器里，首发低价 + 续费原价是常见做法，第二年账单翻倍的时候再想换机器，数据迁移成本已经付出去了。

### 下单前该问自己的四个问题

流量是恒定的还是脉冲的？恒定大流量（视频转码分发、镜像站）适合 unmetered 的高端口；月末才导一次数据这种脉冲型流量，按量配额反而更省钱。

介意被暂停吗？很多大配额套餐超量后不收费，但会暂停到下一个计费周期，对生产业务是致命的。unmetered 不会被暂停，代价是端口宽度固定。

用户在哪？没有好线路，跑再多 GB 也耗在跨网丢包里。

续费价多少？这一条直接决定三年总成本。

## 常见问题

**无限流量会被限速吗？**
看你买的是哪种。unmetered 不会因为跑多了限速，因为端口宽度一开始就固定了；标 unlimited 的商家如果在条款里写了公平使用政策，跑爆了是可能被限速的。判断方法只有一个：翻 ToS。

**100Mbps 的端口一个月能跑多少？**
端口 24 小时满速折算约 32TB。实际会低于这个数，单连接限速、邻居抢占、跨网拥塞都会打折。这个数字的意义是让你知道天花板在哪，不是承诺。

**为什么无限流量套餐的带宽反而比大流量套餐低？**
端口就是成本。商家给你不设上限的流量，就必须控制你占用出口的强度，AAIT 从 30Mbps 到 200Mbps 报价从 299 元涨到 2350 元，就是这个逻辑的极端版本。所以“不限流量”和“大带宽”在同一个套餐里天然对立，选哪个取决于你的瓶颈是账单还是速度。

**住宅 IP 和无限流量是一回事吗？**
不是。住宅 IP 说的是 IP 属性（双 ISP 家宽、纯净度、解锁能力），无限流量说的是计费方式。丽萨两条线都带原生住宅 IP，但美国线里只有 399 元那档是无限流量，新加坡线里只有 Lite 和 Pro 两档是。买之前把这两件事分开确认。

**超量了会怎么样？**
unmetered 套餐不存在超量，端口就是上限；配额型套餐（比如搬瓦工）超了不收费，但会暂停到下一个计费周期，想立刻恢复只能升级套餐。
